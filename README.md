# BYT2026a
Repo for BYT students part 2


1. Accept the collaborator invitation (check your e-mail or https://github.com/notifications).
2. Clone this repository:
   `git clone https://github.com/orka97/BYT2026a.git`
3. Create `sXXXXX.html` (your student ID) with some content.
4. Add a line to `list.html` inside `<body>`:
   `<p><a href="sXXXXX.html">Firstname Lastname</a></p>`
5. `git add`, `git commit -m "..."`, `git push`
6. If the push is rejected: `git pull`, resolve conflicts in `list.html`
   (remove the `<<<<<<<`, `=======`, `>>>>>>>` lines!), then commit and push again.

**Login:** GitHub no longer accepts your account password in the terminal.
When asked for a password, use a Personal Access Token
(Settings → Developer settings → Personal access tokens) or log in through the browser window if one opens.
